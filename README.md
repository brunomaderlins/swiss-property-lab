# Swiss Property Lab

Dashboard exploratório para análise de imóveis residenciais na Suíça.

## Funcionalidades atuais
- Geocodificação de endereços suíços via geo.admin.ch
- Mapa-base swisstopo com alternativa CARTO
- Pontos de interesse via OpenStreetMap/Overpass
- Separação explícita entre proximidade de paradas e frequência real de transporte (ainda não automatizada)
- Simulação preliminar de comprar versus alugar e investir

## Publicação
No GitHub, abra **Settings → Pages → Build and deployment → Deploy from a branch**, selecione `main` e `/ (root)` e clique em **Save**.

URL prevista: https://brunomaderlins.github.io/swiss-property-lab/

## Limitações
Protótipo exploratório: dados externos podem falhar; distâncias em linha reta não representam tempos de deslocamento. Horários de transporte público e impostos cantonais ainda não estão integrados automaticamente. Não usar isoladamente para decisões de compra.
